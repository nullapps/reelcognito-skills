# Report a security issue

Contact the [ReelCognito Support Center](https://reelcognito.zohodesk.com/) privately. Include the affected release, what you expected, what you observed, and the approximate time. Use a synthetic example if one is needed. Keep credentials, admission links, barcodes, order confirmations, payment details and personal information out of reports and GitHub issues.

If a ReelCognito agent token is exposed, revoke it, generate a replacement and reconnect the agent through its secure credential flow. Contact the merchant directly about exposed merchant credentials or tickets. [Agent Connections](https://app.reelcognito.com/settings/tokens)

The public compatibility feed accepts anonymous reads. It has no authority to change the destination for credentials or authorize spending. If verification fails, follow the installed release's failure-handling instructions. Report a suspected integrity issue with the release, UTC time and manifest revision if known.
