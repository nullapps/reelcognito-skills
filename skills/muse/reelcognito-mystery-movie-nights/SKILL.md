## First use

Wait for a separate customer request such as “Start ReelCognito onboarding.” Apply the text between the COPY headings of the [combined v5 instructions](reelcognito-agent-setup-combined-v5.md) once. It includes the interview and the trusted compatibility rules. The [main prompt](reelcognito-agent-setup-prompt-v5.md) and [compatibility companion](reelcognito-agent-patches-setup-v5.md) contain the same two blocks individually.

Conduct the interview and confirm preferences before saving them. Check that Muse offers a supported secure credential connection before guiding the customer through [Agent Connections](https://app.reelcognito.com/settings/tokens). Follow the reviewed one-time-token instructions. If secure storage is unavailable, pause credential provisioning.

At first use, fetch the [live compatibility manifest](https://api.reelcognito.com/agent-patches.yaml) anonymously over HTTPS with redirects disabled. Apply the v5 schema, scope, freshness, revision and failure rules in the combined document. Report the preflight outcome separately from installation. The [bundled YAML](reelcognito-agent-patches-v5.yaml) is a release snapshot. Never use it as a live response, cached fallback, or required digest for a later live response.

End onboarding before choosing a showing, buying, entering payment details or registering a ticket. For subsequent booking requests repeat the v5 compatibility checks at the prescribed times.
